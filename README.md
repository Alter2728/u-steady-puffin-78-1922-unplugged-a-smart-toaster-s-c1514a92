An entry for make.fun's [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/bounty/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) bounty ($2 in USDC): a program that writes a single one-line breakup text from a smart toaster that woke up self-aware at breakfast and wants out.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The line opens on the classic breakup formula with a toaster twist — "It's not you, it's the browning dial" — then gives a concrete grievance: burning every breakfast for an owner who never cleans the crumb tray. The appliance logic (mid-batch awakening, browning dial, crumb tray) is the character of the line rather than decoration, and the reason for leaving lands in one read. The output is deterministic: every run writes the same line, 161 characters as the gate requires (1 line, 1–280 characters, UTF-8, not only white space).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
